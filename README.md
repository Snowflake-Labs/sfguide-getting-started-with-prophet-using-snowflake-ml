# Getting Started with Prophet using Snowflake-ml
## Overview
This guide provides a comprehensive process for creating a [Prophet](https://facebook.github.io/prophet/) forecast model in Snowflake and logging the model in the Model Registry. It will walk you through the steps to build a Prophet model(i.e. custom model), log it into Snowflake model registry, and deploy it for inference using noetbooks

## Step-By-Step Guide
For prerequisites and environment setup, please refer to the [QuickStart Guide]( https://quickstarts.snowflake.com/guide/getting-started-with-prophet-using-snowflake-ml/index.html?index=..%2F..index#0).
