# sfguide-getting-started-with-prophet-using-snowflake-ml
## Overview
This guide provides a comprehensive process for creating a [Prophet](https://facebook.github.io/prophet/) forecast model in Snowflake and logging the model in the Model Registry. It will walk you through the steps to build a custom model, log it into Snowflake, and deploy it for inference.
